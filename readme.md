# DVD Rental BI Dashboard

A professional business intelligence dashboard featuring a **FastAPI** backend, a lightweight **Pure HTML/CSS/JS** frontend, and a **PostgreSQL** database. Integrates a Random Forest classifier for film popularity predictions.

---

## Backend Setup

### 1. Create a Virtual Environment

```bash
cd backend
python -m venv venv
source venv/bin/activate      # Linux/Mac
venv\Scripts\activate.bat     # Windows
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Setup Environment Variables

```bash
cp .env.example .env
```

Open `.env` and fill in your PostgreSQL credentials:

```ini
DB_HOST=localhost
DB_PORT=5432
DB_NAME=dvdrental
DB_USER=postgres
DB_PASSWORD=your_password_here
```

### 4. Ensure Database Views/Tables Exist

The backend requires the following summary tables/views in your PostgreSQL instance:
- `summary_genre`
- `summary_rating`
- `summary_inventory`
- `summary_film_features`
- `fact_rental`
- `dim_genre`
- `dim_film`
- `dim_date`
- `inventory`

### 5. Train the Random Forest Model

```bash
python train_model.py
```
This produces `random_forest_model.pkl`, which is required for the ML prediction endpoint.

### 6. Run the Backend

```bash
uvicorn app:app --reload --host 0.0.0.0 --port 8000
```
- API Endpoint: `http://localhost:8000`
- Interactive Documentation: `http://localhost:8000/docs`

## Frontend Setup

The frontend consists of static pages with vanilla CSS/JS and does not require a build step.

### Option A: Local HTTP Server (Recommended)

To avoid CORS restrictions on local API requests:
```bash
cd frontend
python -m http.server 3000
```
Open: `http://localhost:3000`

### Option B: VS Code Live Server
Right-click `index.html` and select **Open with Live Server**.

## Key Features

### 1. Genre × Rating Analysis Page
Features 4 high-contrast Chart.js visualizations:
- **Chart 1: Rating Composition (100% Stacked Bar)**: Simplifies ratings into two key business segments: **Family-Friendly (G & PG)** and **Mature Audience (PG-13, R, NC-17)**. Sorted by Family-Friendly percentage descending for instant target audience scannability.
- **Chart 2: Top Genres by Content Rating (5-Panel Grid)**: Displays 5 small horizontal bar charts listing the top 5 highest-rented genres for each rating category, eliminating color-decoding guesswork.
- **Chart 3: Genre Popularity (Bar Chart)**: Total rental volume per genre.
- **Chart 4: Overall Rating Distribution (Donut Chart)**: Proportion of overall rentals by movie rating.

### 2. Cleaned Inventory Page
Focuses on stock levels and management:
- **Stock Overview**: Days-to-empty urgency chart, progress bars, and searchable stock status tables.
- **Add Stock**: Allows adding stock units directly to store locations.

### 3. Next Big Hit Prediction Page
- Allows inputting hypothetical or existing film parameters (genre, rating, length, actors, rental cost) to run ML popularity predictions.
- Renders an interactive comparison radar chart indicating features vs popular averages.

### 4. Multi-Theme Customizer
Supports 5 premium stylesheets dynamically:
- **Dark (Default)**: Deep burgundy tones.
- **Light**: Slate-gold palette with high-contrast warm charcoal text.
- **Gold**: Sleek gold-accented dark surface.
- **Midnight Blue**: Premium deep navy background with cyan elements.
- **Forest Emerald**: Premium forest green background with mint elements.

## AI Assistant Integration

The chatbot panel (accessible via the floating bottom-right button) is fully localized to English and provides advanced dashboard controls:
- **Dynamic Context Scraping**: The assistant automatically reads visible table rows on any page, allowing you to ask questions about specific table entries.
- **Radar Chart Reading**: Coordinates from the ML prediction radar chart are formatted on a normalized 0-100 scale, letting the AI analyze and explain feature balances.
- **Embedded Dashboard Actions**:
  - `changeTheme:midnight` / `light` / `dark` etc.
  - `exportData:csv`
  - `recommendFilm:GenreName:RatingName`

### Example Prompts
- *"Give me a business analysis of film genres"*
- *"Forecast stock requirements for the movie Blade"*
- *"Export the current table data to CSV"*
- *"Switch the theme to Midnight Blue"*
